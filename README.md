# One Click Apply
This README was generated by Menace

## Overview
One Click Apply automates job applications by:
- Scraping job postings (CareerPuck, Greenhouse, Workday, etc.)
- Generating tailored field mappings & text via OpenAI (LangChain)
- Filling & submitting forms with Selenium & ChromeDriver

## Features
- Modular agent architecture (in `agent/`)
- Customizable prompt templates & chains (LangChain)
- Form parsing & field extraction (BeautifulSoup)
- Automatic form filling & submission (`selenium_driver.py`)
- Jupyter notebook demo & prototyping (`main.ipynb`)

## Prerequisites
- Python 3.8+
- Google Chrome
- Matching ChromeDriver in project root
- OpenAI API key
- (Optional) GitHub API token for remote file loading

## Installation
1. Clone repo  
   `git clone https://github.com/…/thunder-apply.git && cd thunder-apply`
2. Create & activate venv  
   `python -m venv venv`  
   `venv\Scripts\activate`
3. Install dependencies  
   `pip install -r requirements.txt`

## Configuration
1. Create `.env` in project root:
   ```
   OPENAI_API_KEY=your_openai_key
   GITHUB_API_TOKEN=your_github_token
   ```
2. Edit `profile.json` with your personal data:
   ```json
   {
     "first_name": "Jane",
     "last_name": "Doe",
     "email": "jane.doe@example.com",
     "phone_number": "+15551234567",
     "location": { "full_location":"Toronto, Canada" },
     "resume_path": "assets/resume.pdf"
   }
   ```

## Usage
- Run the AI agent:  
  `python agent/main.py --url <JOB_POST_URL>`
- Directly invoke Selenium filler:  
  `python selenium_driver.py --url <JOB_POST_URL>`
- Prototype in notebook:  
  `jupyter lab main.ipynb`
